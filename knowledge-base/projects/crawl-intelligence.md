# Crawl Intelligence Reporting

**Where:** Amazon, Business Intelligence & Data Engineer
**Stack:** AWS Redshift, Tableau

## Problem
SEO Managers needed to understand exactly how Googlebot was crawling Amazon's URLs — which
pages were being crawled, how often, and how efficiently — in order to redesign sitemaps for
better discoverability, but this data wasn't surfaced anywhere accessible.

## Approach
Vivek designed a comprehensive Crawl Analysis data infrastructure tracking Google's crawl
behavior across Amazon URLs based on **15+ technical factors**, combining Redshift (for the
underlying crawl data) and Tableau (for the reporting layer).

## Outcome
Empowered SEO Managers to optimize sitemap architecture using this factor-level visibility,
improving crawl efficiency by **25%** — directly supporting better product discoverability via
organic search.
